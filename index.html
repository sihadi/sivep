Hybrid Architecture

A layered pipeline combining WMO/OMM regulatory QA/QC with machine learning — missing values and meteorological anomalies handled separately.

OMM RulesWMO regulatory foundation · 25%
MLQC-STSpatiotemporal ML · 25%
Isolation ForestOffline per station · 35%
Supervised RFWhen labels exist · 15%
hybrid_dgm0.65·s_pond + 0.35·s_vote · τ=0.52

Missing-value track

  • NULL, gaps & PDF artifacts (0NULL)
  • KNN imputation with spatial neighbours
  • Separate from weather anomalies

Anomaly track

  • Multi-detector fusion (hybrid_dgm)
  • SHAP explainability for climatologists
  • Human-in-the-loop — raw data never silently overwritten
